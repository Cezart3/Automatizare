=== SHOWER CONFIGURATOR - INSTRUCȚIUNI DE INSTALARE ===

1. EXTRAGETI TOATE FISIERELE INTR-UN FOLDER

2. RESTAURATI BAZA DE DATE:
   - Dublu-click pe "restore_database.bat"
   - Urmați instrucțiunile din fereastra de comandă
   - Introduceți parola MySQL când este solicitat

3. CONFIGURATI CONEXIUNEA:
   - Deschideți fișierul ".env" cu Notepad
   - Înlocuiți "parola_ta_aici" cu parola voastră MySQL
   - Salvați fișierul

4. RULATI APLICATIA:
   - Dublu-click pe "ShowerConfigurator.exe"

5. DACA APAR PROBLEME:

   a) MySQL nu este instalat:
      - Descărcați de la: https://dev.mysql.com/downloads/mysql/
      - Instalați și setați o parolă

   b) Eroare de conexiune:
      - Verificați fișierul .env că are datele corecte
      - Asigurați-vă că MySQL rulează (serviciul "mysql")

   c) Aplicația nu se deschide:
      - Asigurați-vă că aveți Java 21 instalat
      - Descărcați de la: https://www.oracle.com/java/technologies/downloads/
